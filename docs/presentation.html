Rubric Criteria 02 & 06 · Protocol & ACID

Technical Mastery: Cryptographic Handover Protocol

Eliminating in-person delivery fraud and ghosting disputes through atomic cryptographic verification

1. Four-Step Cryptographic Handover Flow
  • Step 1 (Dynamic QR): Seller displays dynamic token QR_HANDOVER_TOKEN_<id>_<nonce> bound to 7-day MongoDB TTL index.
  • Step 2 (Optical Scan): Buyer scans QR via mobile_scanner in < 200ms; sends authenticated claim request.
  • Step 3 & 4 (State Transition): Server commits transaction; seller receives +5 trust points and order is marked complete.
Dynamic Nonce TTL Expiration +5 Trust Reward
2. MongoDB ACID Multi-Document Atomicity
  • All-or-Nothing Commit: Koa executes runMongoTransaction: [Transfer Ownership] ➔ [Seller TrustScore +5] ➔ [Burn Token] ➔ [Complete Order].
  • Automatic Network Rollback: Mid-exchange cellular network dropouts abort cleanly with zero partial state corruption.
runMongoTransaction Zero State Drift Atomic Rollback

Rubric Criterion 09 · Cybersecurity

Cybersecurity & Privacy: Defense-in-Depth OWASP Controls

Proactive mitigation embedded across client apps, API gateway, and database layers

1. Access Control & Cryptographic Defense (A01, A02)
  • JWT Authorization & RBAC: Signed JWT bearer tokens required for mutations; requireAdmin middleware guards governance routes.
  • Bcrypt Password Hashing: User passwords salted and hashed with bcrypt (12 work factor rounds).
  • TLS 1.3 & Secrets Vault: End-to-end HTTPS encryption across Cloudflare edge; zero secrets committed in git.
JWT Bearer requireAdmin RBAC Bcrypt (12 Rounds)
2. Injection Prevention & Server Hardening (A03, A05)
  • NoSQL & ReDoS Defense: Strict Mongoose schemas block query injection; search queries sanitize regex expressions to prevent catastrophic backtracking.
  • Security Header Hardening: Stripped X-Powered-By headers; strict CORS whitelist enforces approved production origins.
  • Masked Error Interceptors: Internal exceptions masked from clients while logged securely on the server.
NoSQL Defense ReDoS Sanitization CORS Whitelist
